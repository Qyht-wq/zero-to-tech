# Zero to Tech

我的第一个 GitHub 仓库。用来练手、踩坑、把零碎的代码片段放在这里。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 第一个 HTML 网页（"你好，git"） |
| `index` | 另一个版本的 HTML（与 `index.html` 内容相同，保留作对照） |
| `kaka.md` | 随手记的笔记 |
| `mine.txt` | 测试文件，已加入 `.gitignore`，不会被 Git 跟踪 |

## 本地运行

直接用浏览器打开 `index.html` 即可：

```bash
start index.html        # Windows
# 或者直接把文件拖到浏览器窗口
```

## 常用 Git 操作

```bash
git status              # 看哪些文件被改动
git add .               # 暂存所有改动
git commit -m "说明"    # 提交
git push                # 推送到 GitHub
```
